📚 Learning Order

The "Java" folder contains different Java programs covering various topics.

Each file has a number at the end of its name, which represents the recommended learning order.

For example:

PRINT_1.java
PRIMITIVE_VARIABLE_2.java
EXAMPLE_IF_OF_BOOLEAN_3.java
REFERENCE_VARIABLE_4.java
SCANNER_5.java
...

The recommended learning order is:

1 → 2 → 3 → 4 → 5 → ...

It is recommended to follow the numbers in order, as the topics gradually build on concepts learned previously.
